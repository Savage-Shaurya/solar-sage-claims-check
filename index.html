1. Efficiency / gain claims⚠️ Needs fix

The arithmetic reproduces, but 10.2% → 2.2%, +12.8% and ₹3.7 lakh rest on a linear 0.26 %/day assumption that real cleaning steps (median 5.9%) do not support.

Fix:

  • Label 10.2% → 2.2% and ₹3.7 lakh/yr "upper-end model estimates"; fix Chapter 7C, which says no saving is claimed.
  • Remove Fig 5.10 and "40–60% fewer flight hours"; restate the 20–30% target (real dust loss 4.9%, routine gain 1.4–1.8%).
  • Give the TinyYOLO test-set size: 91.3% is not k/20 (18/20 = 90%, 19/20 = 95%).

4. Performance Ratio✅ Verified

PR = Yf ÷ Yr (IEC 61724-1). Portal daily PR equals yield ÷ POA energy within 0.5 points on 86% of days. Example, 15 Oct 2026: 3.67 ÷ 4.21 = 87.2%.

Fix:

  • No change needed.
  • Optional, Table 5.10: "Portal PR uses one pyranometer; our PI uses temperature- and tilt-corrected expected energy."
